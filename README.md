# GigaAM Dictation для Android

Локальная русская диктовка поверх любой клавиатуры. Набираете свайпом в Яндекс.Клавиатуре — говорите в маленький микрофон в полосе подсказок — текст вставляется в текущее поле. Распознавание идёт на телефоне моделью **GigaAM v3**, без облака и без аккаунта.

**[Скачать APK](https://github.com/simon100500/gigaam-dictation-android/releases/latest)**

```
поле ввода + клавиатура
        │
        ▼
[ mic ]  ← accessibility-оверлей в правом краю полосы подсказок
        │  тап / удержание
        ▼
AudioRecord 16 кГц → GigaAM v3 Q5_K_M (GGUF, локально)
        │
        ▼
текст → accessibility → текущее поле
```

## Что это

- Отдельное приложение `app.gigaam.dictation`, которое **не меняет Яндекс.Клавиатуру**. Свайп, автокоррекция и словари остаются родными.
- Кнопка появляется **только когда есть фокус в редактируемом поле и открыта клавиатура**. Вне ввода не висит ни пузырь, ни иконка.
- Тап — старт/стоп. Удержание — говорите, отпускаете — вставка. Долгое нажатие на идущую запись — отмена.
- Во время записи кнопка показывает живую звуковую волну; при распознавании — спиннер.
- Модель скачивается один раз (197 МиБ) и работает офлайн. В интернет приложение ходит только за ней.

## Почему не патч Яндекс.Клавиатуры

Патч закрытого APK — это производная работа с проприетарным кодом, сломанная подпись, потеря обновлений и зависимости от сервисов Яндекса, плюс повторная работа после каждого релиза. Здесь Яндекс-клавиатура не трогается вообще: приложение рисует свою кнопку через accessibility поверх её полосы подсказок и вставляет текст в поле. Единственное ограничение — это оверлей, а не «настоящая» клавиша внутри раскладки.

## Возможности

- **GigaAM v3 e2e RNN-T**, квантование Q5_K_M, русский язык, пунктуация и регистр от модели.
- Полностью локально: модель, аудио и текст не покидают телефон.
- Вставка через accessibility: подходит для браузеров, мессенджеров, Compose- и веб-полей; на Android 13+ — как ввод с клавиатуры, без порчи буфера обмена.
- Настройки кнопки: форма (круг / квадрат / шестиугольник), размер (S / M / L), точный сдвиг по горизонтали и вертикали.
- Плитка в шторке: загружает или выгружает модель одним нажатием, не начиная запись.
- Пользовательские замены слов: «джира → Jira», «пулреквест → pull request».
- История последних диктовок на телефоне, без облака.
- Работает поверх любой клавиатуры, не только Яндекс.Клавиатуры.

## Требования

- Android 11 (API 30) и новее.
- Только **arm64-v8a**.
- ~200 МиБ свободного места под модель и ~300 МиБ RAM во время распознавания.
- Тестовое устройство: Honor 400 Pro (Android 15, Snapdragon 8 Gen 3) — распознавание быстрее реального времени.

## Установка

1. Скачайте `GigaAM-Dictation-<version>.apk` из [Releases](https://github.com/simon100500/gigaam-dictation-android/releases) и откройте на телефоне. Разрешите установку из этого источника.
2. Откройте **GigaAM Dictation** и пройдите Setup:
   - микрофон;
   - уведомления;
   - Accessibility;
   - исключение из оптимизации батареи.
3. **Если переключатель Accessibility серый:** App info → ⋮ → **Allow restricted settings**, затем включите Accessibility снова. Это ограничение Android для приложений, установленных не из магазина.
4. Скачайте модель **GigaAM v3 Russian · 197 MiB** (лучше по Wi-Fi).
5. Нажмите **Turn on**. В шторке появится тихое уведомление — это требование Android для микрофона в фоне.

### Плитка в шторке

В списке плиток быстрых настроек есть **GigaAM**:

- нажатие на выключенной плитке загружает модель и включает диктовку;
- нажатие на включённой — выгружает модель и останавливает сервис;
- саму запись плитка не запускает, только готовит или освобождает движок.

Подпись плитки показывает состояние: «Модель загружена», «Загрузка модели…», «Модель выгружена».

## Использование

1. Откройте любое приложение и коснитесь текстового поля.
2. В правой части полосы подсказок появится mic-кнопка. Она появляется после того, как клавиатура доехала, и не дёргается во время анимации.
3. **Тап** — начать запись, второй тап — остановить и вставить.
4. **Удержание** — говорить, пока держите; отпустить — вставить.
5. **Долгое нажатие** на идущую запись — отменить без вставки.

Если кнопка перекрывает иконку клавиатуры, откройте настройки приложения → **Dictation key → Position** и сдвиньте её, либо уменьшите размер. Вертикальный сдвиг позволяет поставить кнопку прямо поверх клавиши микрофона Яндекс.Клавиатуры: касания в этой точке будут уходить в диктовку, а не в клавишу под ней.

## Настройки

| Раздел | Что делает |
| --- | --- |
| Dictation key → Shape | Круг, квадрат или шестиугольник |
| Dictation key → Size | S (32 dp), M (36 dp), L (40 dp) |
| Dictation key → Position | Сдвиг по X (−300…+40 dp) и Y (−40…+360 dp), шаг 1 dp, кнопки − / + |
| Replacements | Замены произнесённых слов на нужные |
| Advanced → Insert text | «Type» (как клавиатура) или «Paste» (через буфер обмена) |
| Advanced → Lower other audio | Приглушать музыку/видео на время записи |
| Advanced → CPU threads | Число потоков распознавания, по умолчанию авто |

## Приватность

- Аудио распознаётся на устройстве; запись не сохраняется после вставки.
- Наружу уходит только HTTPS-запрос за моделью с Hugging Face. Никакой телеметрии, аккаунта или облачного ASR.
- Модель проверяется по SHA-256 перед загрузкой в память:
  `0f5969b05f7e196e8922e243c64963132025a5ae7ec2f83d028ae120d201594f`.
- История диктовок хранится локально; её можно очистить в приложении.
- Приложение не читает содержимое полей: accessibility используется, чтобы найти сфокусированное поле и вставить текст у курсора.

## Как это работает

- **AccessibilityService** слушает появление окна клавиатуры (`TYPE_INPUT_METHOD`) и фокус в редактируемом поле; по bounds окна клавиатуры ставит `TYPE_ACCESSIBILITY_OVERLAY` в полосу подсказок.
- **AudioRecord** пишет 16 кГц моно PCM с источника `VOICE_RECOGNITION`.
- **Rust-ядро** (`android/core`, JNI) запускает `transcribe.cpp` с GGUF-моделью GigaAM и возвращает текст.
- **Inserter** вставляет текст через `InputConnection` (Android 13+) или `ACTION_SET_TEXT` / `ACTION_PASTE`.
- **Foreground service** с типом `microphone` держит модель загруженной и разрешает запись из фона — поэтому в шторке видно уведомление, пока приложение включено.

## Сборка

Нужны:

- JDK 17+;
- Android SDK: platform 36, build-tools 36, platform-tools;
- NDK **27.2.12479018**;
- CMake 3.22.1 и Ninja;
- Rust с таргетом `aarch64-linux-android` и `cargo-ndk`;
- на Windows — Git Bash.

```bash
rustup target add aarch64-linux-android
cargo install cargo-ndk
```

Скопируйте `android/env.local.sh.example` в `android/env.local.sh` (файл в `.gitignore`) и укажите свои пути:

```bash
export ANDROID_HOME="/path/to/Android/Sdk"
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.2.12479018"
export JAVA_HOME="/path/to/jdk-17"
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/cmake/3.22.1/bin:$PATH"
```

Сборка ядра и APK:

```bash
cd android
./build-core.sh          # libhexcore_dotprod.so и libhexcore_base.so
./gradlew assembleDebug  # app/build/outputs/apk/debug/app-debug.apk
```

Release-подпись задаётся переменными `HEX_RELEASE_KEYSTORE`, `HEX_RELEASE_PASSWORD`, `HEX_RELEASE_ALIAS` (см. `android/app/build.gradle.kts`).

## Ограничения

- Только русский язык: GigaAM v3 русскоязычная.
- Только arm64.
- Кнопка — оверлей, а не клавиша внутри раскладки; её положение зависит от того, как клавиатура рисует полосу подсказок.
- Пока приложение включено, работает foreground service с уведомлением.
- Нет live-текста и суммаризации: только диктовка.
- Производительность и поведение оверлея могут отличаться на прошивках с агрессивным энергосбережением.
